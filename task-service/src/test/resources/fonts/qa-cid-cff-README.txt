Original synthetic QA font programs, generated by qa-samples/generate_cff_metadata_fixture.py
with FontTools 4.61.1. Two glyphs: empty .notdef and an authored triangular outline.
No third-party font program or glyph data is copied. Distributed under the repository license.
Base64 JSON is intentional so the tiny CID-CFF metadata fixtures are reviewable and reproducible.
These are metadata/parser unit fixtures, not visual CJK quality samples. Real Noto CJK HTTP
acceptance uses separately installed, licensed source fonts and records their original hashes.
