# 中文 API 可见性拒绝：具体触发对象与有限停止

复用 iteration36 保存的中文长金额编辑前/后 Office PDF，以及一个已成功英文对照；没有新 HTTP 请求或 Office 重开，也没有重复旧矩阵/上一轮本地全量构建。生产源码、JAR、数字/遮罩/可见性与超时门槛不变。

**结论：这组严格拒绝有实际未覆盖源字迹依据，未证明新的坐标或覆盖计算缺陷。** 当前 JAR 真实的嵌入图像 OCR 上限是 1600px。使用相同解析器、归一化器、固定 bundled OCR 和 `PdfOcrVisibility`，中文前后 PDF 复用同一源识别模型，首个触发词均为“核验”：遮罩触及词框，但不包含整个词框。

- 图像矩阵与解析坐标匹配；所有识别词在页面裁剪内；无未知绘制状态，uncertain 区域为空，透明度/混合模式不是本次原因。中文前后 405/415 个操作符，远低于 20000 上限；16 个 cover，低于 512；诊断像素各 114973，低于 250000 预算。
- “核验”有 **77 个源非白像素的单元未被不透明覆盖完全包含**。在仅移除原生文字绘制、保留扫描与后绘制图形的诊断投影中，该词区域仍有 **74 个非白像素、23 个深色像素**，裁剪显示左缘真实字迹残留。该投影用于分析绘制层次，**不是实际最终页面或新的转换产物验收**。
- “编辑”整词没有触及遮罩，是实际仍可见的源字词；投影中有 2211 个深色像素。该行同时有隐藏和未隐藏词，原有 partly-hidden-line 规则也不能靠拼接数字/词放行。
- “编号”“文字”的矩形外剩余部分确实只有白色间隙，属于局部保守拒绝；不能从这两词推导整页无可见字迹，也不能把所有部分覆盖判为白间隙。
- 旧金额 `048.65` 的识别词框被完全覆盖，源非白像素未覆盖数为 0。本次失败由上述中文源内容触发，不是允许旧金额重新流入。英文对照同一真实过滤器成功，与已保存 HTTP 成功一致。

中文原生层 65 字，不足共享扫描覆盖门槛。已有正确新金额、原生文字、OCR 平均置信度，均不能证明其余扫描内容完整。三个已保存中文 HTTP `OCR_VISIBILITY_UNCERTAIN` 继续保持无下载；未新增任何成功/no-op 条件。

`PdfVisibilityTriggerProbe37` 读取当前 JAR 的实际 1600px 常量，记录真实 OCR model、绘制区域、每词过滤判据、像素和预算；中文前后缓存同一源图，只新增两次正确尺寸的源识别（中文、英文各一次）。首版 helper 用了错误边长，完成一次 2000px 识别后遇到重名目录冲突；该失败及数据保留，不计为生产路径验收。合计源识别调用 **3 次**。`PdfCoverResidualRender37` 只生成两份绘制层次诊断投影，OCR/HTTP/Office 均 0；`verify_visibility37` 核对源/产物哈希、触发对象和退出证据。验证器首版误检查自己的未完成 receipt，修正为在最终收尾检查；失败记录保留。没有后台残留或新并行写入。

沿用精确生产源码已经通过的 **502 项：501 通过、1 可选签章夹具跳过**，10 项命名 bundled 条件测试实际执行；本批未再执行该全量。JAR 仍为 `73b2aada867097614e5ed3bae08a840a8a232b313c8595075086c5c5254dc597`，构建指纹仍为 `8c0313636afba2fc18ad2db414e3952de7c5a38050aadfd83f9355faa3d7acd9`。固定 Tesseract 5.5.2/Leptonica 1.87.0、fast 模型、工具和字体精确版本沿用 [iteration36](cloud-long-amount36.md)，未切换模型或参数。完整触发对象和哈希见 [结果](cloud-visibility37-results.json)，实际 model/TSV/裁剪/投影/receipts 在忽略的 QA 证据目录。

**不同的可测高价值问题：嵌入图像 1600px 归一化的数字保真。** 同一缓存中文源图，初次 2000px 原尺寸 TSV 的标题数字是正确 `2097`；实际 1600px 路径变为 `“097`，词置信度分别 89.33% / 83.97%。这只是已有诊断缓存的独立观察，未验收新 API 或建议直接提高尺寸限制。下一有限批可冻结少量独立中英文混合 PDF 的数字/前导零/符号与不同字号，比较精确数字字面量、CER/遗漏、时间/RSS，在原像素和页级时限内测量是否有安全收益；不能用置信度代替完整性、为通过旧负例放宽 gate，或把 Word 布局收益称为识别提升。

本批在已有明确实际字迹反例处停止，不再重复这一无安全修复收益的可见性调查。相邻长编辑、中文/先前 mixed API、原稀疏 OFD、源冲突语义、Mac/Windows 原生安装器、Microsoft Word 和签章夹具限制继续保留；同一草稿 PR/检查点交既有父会话/dot 协调后续有限问题，无 merge/release/Mac/Library 重试或外部上传。
