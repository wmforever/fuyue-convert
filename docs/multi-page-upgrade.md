# 完整多页转换升级说明

## 行为保证

`OfdParser.parse` 按 1 到 `sourcePageCount` 顺序解析所有页面。每页分别提取文字、Path、图片、页面尺寸和警告，再分别执行段落分析与有线表格识别。解析器不再提供“只解析第一页”的生产入口。

`PoiDocxRenderer` 把每个 `PageModel` 写入同一个 DOCX：

- 页面之间使用 Word `nextPage` 分节；
- 每个分节分别写入页面宽度、高度、方向和页边距；
- 每页文字仍是真实 Run/Paragraph；
- 每页表格仍是真实 Word Table；
- 独立图片按元素写入，不创建整页截图。

任务结果中的 `files[].pageCount` 返回实际完成转换的页数。若源页数超过安全配置 `ofd2word.max-pages`，任务返回 `OFD_TOO_MANY_PAGES`；不会只输出前若干页后伪报成功。

## 跨页表格边界

当前每一页独立识别表格，因此跨页表格的上下两段都会完整输出为可编辑表格，但暂时是两张 Word 表格。后续升级将依据列网格、边框、表头和页面边缘位置判断连续关系，在置信度足够时合并并设置重复表头。
