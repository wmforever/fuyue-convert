# 扫描 PDF → Word 的叠加边界

本策略用于显式开启 `-Dformatconverter.ocr.safe-overlays=true` 的开发对照实验，以及显式选择的 [RapidOCR 实验路线](rapid-ocr-local.md)。常规 Tesseract 路线默认关闭：其真实样本的整行回退会使可编辑覆盖率大幅下降。默认 Tesseract 路线保留 OCR 文本，仅应用字号、宽度和纵坐标修正。

扫描图和 OCR 文本直接叠加会产生重影。表格线被识别为字母、过高的文字框和跨行的联合框还会产生异常字号或错位。平均 OCR 置信度不能证明这些区域可安全编辑。

PDF 的可编辑转换在布局分析前检查纯扫描页。只有整条 OCR 识别行的词框均能安全替换时，才生成该行的可编辑文字；否则保留该行的原始扫描内容。不会补造字词、按置信度改写数字，或把未采用的 OCR 文字藏进文档。

检查包括局部纸色、彩色标记、词框重叠、异常高度和低置信度。近白纸页允许用已验证的上下边缘估计被相邻粗体字干扰的纸色，不扩大词框覆盖范围。暗纸页及未知纹理保留扫描内容。OCR 稠密页限制检查规模，超限明确回退。原生文字页与混合原生/OCR 页沿用已有路径。

字号估计结合词框宽高，并用充分数量的可靠词估计页面尺度。没有正文尺度证据的稀疏标题页保留大字号。不同表格行的词保留各自纵坐标，避免被联合框拉到同一行。

默认路线也保留异常识别候选的可编辑文本，但将明显过高或过宽的低置信度词约束到可靠正文的字号，避免表格线预测产生巨型字。此类词不允许用明亮中性纸色遮罩覆盖未知表格内容；原扫描仍可见。这个保护不把错误预测改写成正确文字，重影和识别错误仍需后续处理。

发生回退时，任务返回 `OCR_REGION_RETAINED_AS_IMAGE` 警告，给出页码、未转换片段数量和受限长度的识别候选。没有可编辑文字的页面明确提示整页为扫描图。Word 文档属性也说明部分区域不可直接编辑。输出页数和原扫描图字节保持完整。

这项处理改善显示稳定性，不提高 OCR 字词准确率，也不恢复原生 Word 表格。可编辑覆盖率可能下降，尤其是彩色扫描、灰底表格和复杂版面。TXT 提取仍保留引擎的识别结果，不应用这个显示回退规则。

验证包括错误框与可靠词的碰撞、彩色印章保护、原图字节完整性、回退警告及 Word 属性、稀疏标题字号、跨行定位、暗纸和原生文字兼容性。真实扫描样本还需执行完整 PDF → DOCX 转换，再用 Office 渲染检查全部页面；不能仅凭转换成功或单元测试通过认定可用。
