# 已知限制

1. 多页已完整转换，但相邻页面上视觉连续的跨页表格当前分别生成为两张真实 Word 表格，尚未自动拼成同一张跨页表格。
2. 只识别由水平/垂直矢量线构成的规则表格；无线、嵌套和异形表格尚未实现。
3. Path 中的曲线、圆弧和内部 `CM` 变换不参与表格边线识别。
4. 图片当前以可移动的 Word 图片内容保留，但尚未实现严格的 `wp:anchor` 页面绝对坐标。
5. 未实现扫描型 OFD 的本地 OCR 引擎；已提供 `OcrEngine`、请求与结果 SPI，当前只返回 `OCR_REQUIRED` 警告。
6. 加密 OFD、私有厂商扩展和部分数字签章外观可能无法解析；系统会失败或给出警告，不会伪造成功。
7. 同 JVM 的转换时限目前是阶段间协作检查，不是可强制杀死第三方库的硬超时；生产强化阶段应采用隔离 Worker JVM。
8. 尚未用真实样本证明 95% 表格准确率；必须在约定验收集上测量后才能给出指标。
